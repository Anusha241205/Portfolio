# Anusha — Developer Portfolio

A responsive React + CSS portfolio built with Vite.

## Run locally

1. Install Node.js (LTS).
2. Extract this project and open the folder in VS Code.
3. In the terminal, run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Before publishing — personalize these details

- In `src/App.jsx`, replace `YOUR_EMAIL@example.com` with your real email address.
- Replace the LinkedIn placeholder URL with your LinkedIn profile URL.
- Check each project link and update it to the correct repository/demo.
- Add your latest resume as `public/Anusha-Resume.pdf` and add a resume download link if you want one.
- Confirm your education dates and CGPA before sharing publicly.

## Build for deployment

```bash
npm run build
```

Deploy the generated `dist` folder to Vercel or Netlify. For Vercel, import the GitHub repository and keep the build command as `npm run build` and output directory as `dist`.
